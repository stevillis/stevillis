Profissional de tecnologia com sólida base em Desenvolvimento de Sistemas, com atuação focada nas áreas de **Ciência de Dados e Engenharia de Dados**. Pós-graduado em Gestão e Ciência de Dados pela UFMT, meu objetivo é a **transformação de dados complexos em insights práticos**, apoiando a tomada de decisão estratégica por meio de análises exploratórias, automação de rotinas de dados (ETL) e modelagem preditiva.

Com experiência prática em bancos de dados relacionais de larga escala, possuo domínio na criação e manutenção de rotinas avançadas de extração e transformação de dados (Oracle SQL, PostgreSQL). Além disso, aplico técnicas de Machine Learning, desenvolvendo modelos e ferramentas analíticas que otimizam processos operacionais e geram grande valor de negócio.

Visite o [meu portfólio](https://stevillis.com.br) para conhecer em detalhes os meus projetos na área de Dados e entrar em contato.
